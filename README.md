# Matreshka RP Trainer

Тренажёр подготовки к аттестации администратора Матрёшка RP.

- адаптивный интерфейс для ПК и телефона;
- теория, шпаргалки и наказания;
- 15 случайных вопросов в попытке;
- проходной балл 80%;
- объяснение ошибок;
- последовательное открытие тем;
- прогресс хранится в localStorage;
- учебные данные вынесены в `rules-data.js`.

Важно: это учебный тренажёр. Перед использованием формулировки и наказания необходимо сверять с актуальными официальными правилами проекта.
